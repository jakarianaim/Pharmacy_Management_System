# \## Pharmacy Management System

# 

# <small>Welcome to my Java Pharmacy Management System repository. This project was developed as part of the OOP1 course to build practical skills in Java programming and Object-Oriented Programming (OOP). It focuses on managing essential pharmacy operations, including medicines, customers, sales, and inventory.</small>

# 

# \### 💊 Key Features

# 

# \#### 1. Medicine Management

# \* <small>Add, update, delete, and search medicine records.</small>

# \* <small>Manage medicine information and details.</small>

# 

# \#### 2. Customer Management

# \* <small>Store and manage customer information.</small>

# \* <small>Maintain customer records.</small>

# 

# \#### 3. Sales \& Billing

# \* <small>Manage medicine sales and calculate purchase totals.</small>

# \* <small>Generate invoices for customers.</small>

# 

# \#### 4. Inventory Management

# \* <small>Track available medicine stock.</small>

# \* <small>Monitor medicine quantities and low-stock items.</small>

# 

# \#### 5. Object-Oriented Programming (OOP)

# \* <small>Classes and Objects: Organizing the system into reusable components.</small>

# \* <small>Encapsulation: Protecting data using access modifiers.</small>

# \* <small>Inheritance: Reusing common features across related classes.</small>

# \* <small>Polymorphism: Using method overloading and overriding.</small>

# \* <small>Abstraction: Simplifying implementation details.</small>

#
