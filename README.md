# \# Pharmacy Management System

# 

# A Java-based Pharmacy Management System developed as part of the Object-Oriented Programming 1 (OOP1) course. This project demonstrates the use of OOP principles in managing basic pharmacy operations.

# 

# \## Features

# 

# \- Medicine Management: Add, update, delete, and search medicines.

# \- Customer Management: Store and manage customer information.

# \- Billing System: Calculate sales and generate invoices.

# \- Stock Tracking: Monitor medicine quantities and low-stock items.

# \- User Login: Support admin and employee authentication.

# \- Data Storage: Store records using file handling.

# 

# \## OOP Concepts Used

# 

# \- Classes and Objects

# \- Encapsulation

# \- Inheritance

# \- Polymorphism

# \- Abstraction

# 

# \## Technologies Used

# 

# \- Language: Java

# \- IDE: NetBeans

# \- Data Storage: File Handling

# \- Version Control: Git and GitHub

# 

# \## Project Objective

# 

# The objective of this project is to apply Java OOP concepts to a practical pharmacy management system and simplify the management of medicines, customers, sales, and inventory.

# 

# \## How to Run

# 

# 1\. Clone or download the repository.

# 2\. Open the project in NetBeans IDE.

# 3\. Build the project.

# 4\. Run the application.
